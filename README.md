# Plando - Personal Todo Web App

Plando is a personal todo web application built for educational purposes, 
focusing on modern web development practices and clean architecture principles.

## Tech stack

### Backend
- C# 14 / .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- JWT Authentication

### Frontend
- React 19
- TypeScript
- Tailwind CSS
- Axios

## Architecture
- Clean Architecture (Domain, Application, Infrastructure, API)
- CQRS (Command Query Responsibility Segregation)
- Repository Pattern
- Dependency Injection

## Features
- Task management (create, update, complete, delete)
- Task Lists
- Task Categories
- Notes per task
- Eisenhower Matrix visualization with drag & drop
- Calendar view (Year, Month, Day)
- Task scheduling (TaskItemSchedule)
- User account management

## Testing
- Backend: xUnit, Moq
- Frontend: Jest, React Testing Library
